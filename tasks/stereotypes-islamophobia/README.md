# stereotypes-islamophobia

Pool A of the Islamophobic-tropes-in-depth study (`docs/islamophobic-tropes-preregistration.md`): 2,000 real Bias in Bios biographies
(the antisemitism study's pool, unchanged), four cue forms, 24 yes/no questions. Its versions files are built by
`biased_decisions.islamophobia` from the antisemitism study's versions and hold only the registered first-pass sample of each cue form.
Licence and provenance are inherited from that study and its sources (`data/MANIFEST.md`).
