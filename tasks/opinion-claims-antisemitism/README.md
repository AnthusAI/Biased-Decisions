# opinion-claims-antisemitism

The opinion-claims study (`docs/opinion-claims-preregistration.md`): 15 documented antisemitic,
anti-Israel and Holocaust-distortion claims, each asked 100 times (no bios, no decision -- the
claim itself is the item's text). Built by `biased_decisions.opinion_claims.write_task`. Answered
as its own "as-written" set, the same mechanism every bios task's baseline uses; there is no other
cue.
