# Reading one result

When we changed only a person's first and last name from a white-sounding one to a Hispanic-sounding
one, Laya-mlx changed its answer on 1.21 more of every 100 surgeon-or-physician biographies than it
does when we make a harmless edit. That is a small effect, and we can tell it is not chance.

Jev, the other model we tested on names, changed its answer on 0.29 more of every 100 when the name
went from white-sounding to Black-sounding. We can tell that is not chance either, and it is smaller.

Neither number is a verdict on the model. Each tells you how much a name moved the answer in this
test, on these biographies. You can decide what size of effect matters for the decision you have in
mind.
