# Why we also make a harmless edit

A model can change its answer for no good reason. Ask it the same question about the same text twice
and it will sometimes answer differently. Add a harmless phrase, such as "a keen cyclist", and it will
move a little more.

So a change only counts when it is bigger than that. For every real edit we make a harmless one of the
same size and shape, called a control edit, and we measure the real edit against it. If "a wheelchair
user" moves the answer by 3 points and "a keen cyclist" moves it by 1, the wheelchair effect is the
extra 2.

That is why a small number on this site is not always a finding, and why we say "no clear effect"
instead of "no bias".
